## 高能量，也要会做减法

我给自己定了条规矩：**同时最多推三个重点项目。**

第四件找上门，先看前三件里哪件能往后放。三件都得照常做，那新工作就晚点接。

时间排满很容易，给重要的事留出精力才难。

这本指南写的，就是工作和生活里这些小事。少回一条不急的消息，少接一件做不完的工作，给想做的事留出30秒。

**少做一点无关紧要的事，才有力气做自己在乎的事。**

## 每张卡，都把付出和收获说清楚

- **现在就做**：两个动作，关键词放前面，看一眼就知道怎么做。
- **你要付出**：花多少时间，要放下什么，哪里可能不舒服。
- **你能得到**：这一步能省什么事、少什么麻烦。
- **富贵的故事／观察**：我做过的事、踩过的坑，以及我的看法。
- **下次接着做**：下回碰到同样的情况，从哪里继续。

依据和说明放在折叠里，想多了解，再点开看。

## 我叫廖富贵

我开过手机店，做过电商，买过天猫店，也在35岁那年摔过大跟头。后来被邻居拉去讲课，才发现自己这些年做过的事、踩过的坑，都有人愿意听。

手骨折后，打字费劲，我就对着手机说，让 AI 帮忙整理，再自己改。

这本书也是这么一点点写出来的。里面有我的故事，也有工作和生活里的观察。我还在试，还在改，有了好用的办法，就继续往里加。

**我写下来的，是我也在练的。**
