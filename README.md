## 🛠️ 如何用 AI 工具一键调用本仓库？

本仓库原生适配 **Codex、WorkBuddy、Claude Code、Cursor** 等现代 AI 协作工具：

### 1. 在 Codex / Cursor 中使用
把本项目 clone 到本地后，AI 编程助手会自动读取根目录下的规则文件：
- 输入：`富贵，我卡住了` 或 `/急救 [你的问题]`
- AI 将严格遵循廖富贵清单体人设，直接定位对应行动卡并吐出两步微动作，零废话。
- 规则配置详见：[.codex/instructions.md](.codex/instructions.md)

### 2. 在 WorkBuddy / 飞书中挂载
直接在 WorkBuddy 知识库中挂载本仓库地址或上传全书清单，输入触发词即可一键获得“廖富贵能量搭子”的现场响应。

## 👤 关于作者

我叫廖富贵。早年在线下开店修手机、卖手机，后来做电商、买天猫店，顺风顺水过，也在 35 岁那年摔过大跟头。再后来被邻居拉上讲台，把自己在泥地里摸爬滚打的经验讲给别人听。一直到现在，我还在试新工具、改自己的干活方式，也还是会踩坑。

我没上过一天班，没什么光鲜履历，也不懂那些绕来绕去的大词。这本小册子，就是把我走过的路、踩过的坑、在课堂上见过的真事，拆成一条条咱们今天就能试的小动作。

**今天不用改变整个人生。先做一件小事，就很好。**
