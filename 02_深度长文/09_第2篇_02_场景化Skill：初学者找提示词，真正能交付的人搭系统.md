## 01. 提示词崇拜：一场现代版的“求签问卜”

大家静下心来想一想，你平时是怎么用 AI 的？

是不是遇到一个麻烦了，比如“想写一篇招生文案”，然后打开聊天框，脑子里现琢磨两句词：  
> “请帮我写一篇吸引 30 岁职场人学 AI 的朋友圈文案，要求有吸引力、痛点深刻、能促成转化。”

然后一敲回车，屏住呼吸盯着屏幕，跟买彩票开奖一样等它吐字。吐出来的结果如果刚好还行，你就阿弥陀佛；如果吐出来一堆“在当今快节奏的职场中，犹如逆水行舟”，你就长叹一口气：“唉，AI 还是不行。”

这叫什么？**这叫数字时代的“求签问卜”。**

你每次给它的原材料都不一样，你给它的背景约束模模糊糊，你连自己要的最终交付规格都没定义清楚，你凭什么指望一个几千公里外服务器里的算法，能猜中你今天中午的心思？

单次的 Prompt，只能解决“随手问答”；  
而商业交付要的是**“确定性”**——不管今天天气好不好、不管你心情烦不烦，按下按钮，出来的东西必须在 80 分以上，随时能拿出去换钱。

要达到这种确定性，你必须把零散的提示词，升级为**“场景化 Skill”**。

## 02. 什么是“场景化 Skill”？（流水线思维）

在工业时代，福特发明流水线之前，每个造汽车的工匠都是“手艺人”。今天心情好，螺丝拧得紧一点；明天跟老婆吵架，轴承装歪了两毫米。这叫手工作坊。  
福特做的事情很简单：把造一辆车的整个过程，切成若干个固定的工位。这个工位只管装轮胎，那个工位只管喷车漆。

**所谓的“场景化 Skill”，就是你在 AI 时代为自己搭建的一条“一人流水线”。**

它不是一句飘忽不定的咒语，而是一个拥有固定结构、专门解决某一个特定商业场景的“数字处理车间”：

```text
┌────────────────────────────────────────────────────────┐
│                   场景化 Skill 核心结构                  │
├────────────────────────────────────────────────────────┤
│ 1. 角色与边界约束（人设卡、禁忌词、核心价值观）          │
│ 2. 规范化输入模版（强制投喂的一手脏数据要素）            │
│ 3. 多阶段处理逻辑（第一步去噪、第二步提炼、第三步转译）    │
│ 4. 固化输出交付规格（字数、排版、配图提示、三端适配）    │
└────────────────────────────────────────────────────────┘
```

举个我们自己的实战例子。在“富贵公司”的知识库里，我们从来不用临时的提示词写公众号，我们使用的是一个叫 `【廖富贵口语转译 Skill】` 的固定工作流：
- **约束端**：预载《廖富贵现场口语表达人设卡》，严禁出现“不仅是更是”、“犹如明灯”，严禁开头说“好，来”，强制注入自嘲；
- **原材料端**：每次只喂给它一段我线下的 3 分钟录音转写文字（脏数据）；
- **输出端**：强制要求第一段抛冲突，中间包含一个 69.9 元暖水袋式的真实小人物故事，文末带一个 5 分钟行动清单。

每次我们要出内容，把手机录音往里一贴，两分钟之内，一篇标准的“廖富贵风格”母稿就出来了。这叫确定性，这叫工业化。

## 03. 搭建商业级 Skill 的四个核心组件

如果你想把自己行业里的某个绝活搭成一个 Skill，记住以下四个关键零件：

### 零件 1：角色与负向禁令（立规矩）
很多人的提示词只写正向要求（“请你扮演一个专业的文案专家”），这根本没用。  
**真正决定质感的，是“负向禁令”（什么绝对不能做）。**  
- “严禁使用任何宏大叙事与虚妄副词（显而易见、不可否认）”；
- “严禁使用对称工整的四字排比句”；
- “如果遇到不确定的行业数据，严禁编造，必须主动反问我”。  
有了规矩，AI 才不会放飞自我。

### 零件 2：输入卡扣（原材料质检）
明确告诉 AI：如果我给你的原材料不达标，你有权拒绝开工，并提示我补齐。  
比如设计一个《客户报价单生成 Skill》：
- 必须包含：客户预算区间、核心痛点、竞品报价、我方底线筹码。
- 如果缺任何一项，AI 必须先反问：“老板，竞品报价是多少？请补齐后再生成。”

### 零件 3：分步执行链（拒绝一步登天）
不要让 AI 在一个回复里同时完成“分析痛点、构思结构、撰写成稿、优化词句”。人脑都做不到，AI 也会注意力涣散。  
把它拆解成连续的步骤：
- 第 1 步：先从原材料中抽取出 3 个核心商业矛盾；
- 第 2 步：列出 3 个不同的叙事切入角度供我选择；
- 第 3 步：在我确认角度后，再生成正文初稿。

### 零件 4：固化交付模板（拿来即用）
输出的结果必须是结构化的，带 Markdown 表格、带检查复选框、带排版样式，让你连排版软件都不用开，复制出来就能交差。

## 04. 一人公司的“五大核心 Skill 矩阵”

一个人就是一家公司。但你不需要给自己招聘 5 个员工，你只需要把以下 5 个场景沉淀成你的专属 Skill：

```text
1. 获客端：【一手痛点提炼与爆款选题 Skill】
2. 内容端：【口语原声 ➔ 三端全媒体转译 Skill】
3. 转化端：【高意向咨询与异议化解话术 Skill】
4. 交付端：【学员/客户问题 123 诊断诊断卡 Skill】
5. 沉淀端：【单次交付案例脱水与资产入库 Skill】
```

当这 5 个流水线车间在你的 Obsidian 知识库里搭建完毕，你每天的工作节奏就会发生天翻地覆的变化：
- 早上起来，你不再对着空白屏幕发呆；
- 遇到客户咨询，调出 Skill，输入两句原话，优质回应方案瞬间成型；
- 晚上复盘，调出入库 Skill，当天的实战经历自动提炼进资产库。

这时候，你才真正跨越了“体力出卖者”的门槛，成为了一名掌控数字杠杆的一人企业操盘手。

## 05. 富贵行动清单：今天搭出你的第一个商业 Skill

别把事情想得太宏大。按“做好一件小事”原则，今天下午就完成这一个动作：

1. **选一个你每周都要重复做两次以上的文本工作**：比如给客户写跟进汇报、给朋友圈写一条业务动态、给团队交代任务。
2. **写下你的 3 条负向禁令**：你在看下属或同行写这类内容时，最恶心看到的 3 个毛病是什么？
3. **把你的输入要素与输出格式整理好**。
4. **保存为一个固定的 Markdown 模版文档**，命名为 `【我的_XX任务_Skill】`。

从此以后，这个活你再也不需要重新构思一遍，让 AI 替你打好第一层底稿。
